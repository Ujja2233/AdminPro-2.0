# 🚀 AdminPro 2.0 – Modern Admin Dashboard

A modern, responsive, and feature-rich admin dashboard built using HTML, CSS, JavaScript, and Firebase. AdminPro 2.0 provides a clean interface for business management, user authentication, and cloud-based data storage.

## 🌐 Live Demo

**[View AdminPro 2.0 Live Demo](https://adminpro-30.vercel.app/)**

## 📸 Project Overview

AdminPro 2.0 is designed to simplify administrative tasks through a modern dashboard interface. It provides user authentication, account management, and business record management with a responsive design.

## ✨ Features

- Modern and responsive admin dashboard
- User Registration and Login
- Firebase Email and Password Authentication
- Google Sign-In integration
- Facebook Login integration
- User Profile Management
- Protected Dashboard
- Secure Logout functionality
- Firebase Cloud Firestore integration
- User-specific business data management
- Responsive user interface
- Local browser data management (where applicable)

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/AdminPro-2.0.git
```

### 2. Open Project Folder

```bash
cd AdminPro-2.0
```

### 3. Open in VS Code

```bash
code .
```

### 4. Configure Firebase

1. Visit [Firebase Console](https://console.firebase.google.com/).
2. Create a Firebase project.
3. Enable Email/Password authentication.
4. Configure Google and Facebook providers if required.
5. Create a Cloud Firestore database.
6. Add your Firebase configuration to the project.
7. Add your deployment domain to Firebase Authorized Domains.

**Security Note:** Never expose Firebase Admin SDK credentials or private service account keys in frontend code. Configure Firestore Security Rules to protect user-specific records.
